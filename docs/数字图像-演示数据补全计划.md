## 5. 任务模板（数字图像 · 每组一份，状态按波形推进）

```
T1 需求与数据集准备（调研）     → 多已完成
T2 图像采集与标注               → 依赖 T1
T3 预处理与增强（编程）         → 依赖 T2
T4 经典增强对比实验             → 依赖 T3
T5 分割/特征实验                → 依赖 T3
T6 风格迁移原型                 → 依赖 T4,T5   ← 常作关键路径
T7 实验记录与图表（设计）       → 依赖 T4,T5
T8 撰写报告与口径统一（写作）   → 依赖 T6,T7   ← 延期高发
T9 答辩 PPT 与复现说明          → 依赖 T8
```

状态事件时间线：近 3–4 周内交错 `todo→doing→reviewing→done`，部分 `doing→blocked` / `reviewing→doing`（返工）。

## 6. 实施步骤（执行顺序）

| 步骤 | 内容 | 产出 |
|---|---|---|
| S0 | 解析 xlsx → 内存结构（学号/姓名/双排名/双分） | `scripts/data/rankings.json` 或内嵌 |
| S1 | 建课 DIGI201 + 3 班 + 119 账号/选课/技能卡/画像/社交边 | 名单、班级、技能卡可展示 |
| S2 | 约束 8–10 条 + 分组 run/plans + 每班蛇形落 24 组（classId） | 分组工作台、小组管理 |
| S3 | 每组：任务模板 + 依赖 + RACI 指派 + 状态事件 + 契约与签署 | 任务/契约/我的部分 |
| S4 | 每组：交付物多段撰写/修订 + progress_signals + 健康度快照 | 交付物、健康度、预警 |
| S5 | 冲突（全组）+ 部分归因/处理；危机组重规划事件+3 方案 | 冲突中心、重规划 |
| S6 | 互评一轮（部分完成+异常）→ computeGroupContributions → 终审/锁定样例 + 申诉 | 贡献账本、互评、成绩 |
| S7 | 通知、审计、ai_call_logs；核对各页面非空 | 演示就绪 |

脚本：新建 `web/scripts/seed-digital-image.ts`（幂等：按邮箱域名 `@copaddle.local` / 课程 code `DIGI201` 先清后建）。  
运行：`pnpm tsx scripts/seed-digital-image.ts`（依赖 db + algo；algo 仅可选）。
